cua-s1.js cua-s1-4b in the browser

cua-s1-4b-0.1 is a LoRA on Qwen3.5-4B. It is shown one screen as an accessibility tree and a closed list of (element, action) options, one letter each, and picks the single best next action in one forward pass, on WebGPU. The screens below come from Cua's own task generator (cua-bench-s1); ✓ marks the options its answer key accepts. The first visit downloads 4.7 GB.
